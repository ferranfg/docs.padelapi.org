## The story

Padel API is founded and led by [Ferran Figueredo](https://ferranfigueredo.com), a software engineer and entrepreneur with 15+ years of experience building digital products, based in Spain, the world capital of padel.

It started as the data layer behind [Fantasy Padel Tour](https://fantasypadeltour.com), the first online padel fantasy game running since 2022, trusted by over 7,000 padel fans, and grew into a standalone product as demand from third-party developers increased. Padel API has been available as an independent product [since October 2025](/blog/20251022-whats-new-in-padel-api-oct-2025-new-paid-plan-expanded-coverage-and-more).

## Why Padel API exists

Padel is the fastest growing racket sport in the world, but its data infrastructure hasn't kept up. Developers building apps, analytics tools, or AI integrations have no single reliable source to work with.

Padel API was created to fix that, becoming the first REST API for professional padel results: structured, consistent, and well-documented, covering the full professional circuit from Premier Padel Majors to FIP tournaments.

## How the data works

Data is collected from different sources and goes through a review process running in parallel with availability, ensuring both quality and immediacy. AI assists throughout the pipeline: from detecting inconsistencies in results to enriching player records and flagging anomalies that would otherwise require hours of manual work.

That same approach extends to how you can consume the data. [Padel Analyst](/padel-analyst/index) lets you connect AI assistants like Claude or ChatGPT directly to the API, so you can ask natural language questions about players, matches, and tournaments without writing a single line of code.

## What we cover

Premier Padel, FIP, and World Padel Tour events across multiple seasons, including draws, match results, point-by-point, player stats, rankings, and live scoring. See the full [tournament coverage table](/index#tournaments-coverage) for details.
