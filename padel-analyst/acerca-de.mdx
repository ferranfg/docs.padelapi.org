## Empieza en 3 pasos

Padel Analyst es un servidor [MCP (Model Context Protocol)](https://modelcontextprotocol.io/introduction) que conecta tu asistente de IA con datos profesionales de pádel, para que le preguntes en lenguaje natural sin escribir código. Conéctalo en tres pasos:

<Steps>
  <Step title="Suscríbete al Plan Plus">
    Regístrate en el [Plan Plus](https://padelapi.org/billing) (19€/mes) que incluye:
    - Hasta 50K peticiones/mes
    - Acceso al servidor MCP
    - Funciona con ChatGPT
    - Consultas en lenguaje natural
    - Soporte básico
  </Step>
  <Step title="Crea un Token de API">
    Genera tu token personal de API desde la página de [Tokens de API](https://padelapi.org/user/api-tokens). Lo necesitarás para autenticar las peticiones MCP.
  </Step>
  <Step title="Conecta tu asistente de IA">
    Elige tu asistente y sigue la guía de instalación para empezar a preguntar:
    <CardGroup cols={2}>
      <Card title="Conéctalo a ChatGPT" icon="comments" href="/padel-analyst/chatgpt">
        Añade Padel Analyst en el modo Desarrollador de ChatGPT.
      </Card>
      <Card title="Conéctalo a Claude" icon="robot" href="/padel-analyst/claude">
        La forma más fácil — añádelo como conector, sin archivos de configuración.
      </Card>
    </CardGroup>
  </Step>
</Steps>

## Herramientas Disponibles

El servidor MCP de Padel Analyst proporciona 16 herramientas para consultar datos de pádel:

| Herramienta | Descripción |
|-------------|-------------|
| `list-pair-matches` | Obtener todos los partidos de una pareja de jugadores |
| `list-player-matches` | Obtener todos los partidos de un jugador |
| `list-player-rankings` | Obtener las posiciones del ranking y el histórico semanal de un jugador |
| `list-rankings` | Obtener el ranking FIP de una semana, incluyendo los que más suben y bajan |
| `list-tournament-matches` | Obtener todos los partidos de un torneo |
| `search-headtohead` | Buscar enfrentamientos directos entre jugadores |
| `search-matches` | Buscar partidos con varios filtros |
| `search-pairs` | Listar parejas de jugadores que han jugado juntas, con su estado y fechas de partidos |
| `search-players` | Buscar jugadores por nombre, nacionalidad, categoría o lado |
| `search-seasons` | Explorar temporadas y competiciones disponibles |
| `search-tournaments` | Buscar torneos por nombre, nivel o rango de fechas |
| `show-match-live` | Obtener los datos punto a punto de un partido |
| `show-match-stats` | Obtener estadísticas detalladas de un partido, incluyendo datos punto a punto |
| `show-pair-stats` | Mostrar estadísticas de una pareja de jugadores |
| `show-player-stats` | Mostrar estadísticas detalladas de un jugador |
| `simulate-match` | Simular el resultado de un partido basándose en estadísticas |

## Prompts Disponibles

Los prompts preconfigurados ayudan a estructurar tareas de análisis comunes:

| Prompt | Descripción |
|--------|-------------|
| `head-to-head` | Comparar resultados históricos entre dos jugadores/parejas |
| `match-preview` | Generar una previa de un próximo partido |
| `pair-analysis` | Analizar el rendimiento y estilo de juego de una pareja |
| `player-comparison` | Comparación lado a lado de dos jugadores |
| `player-profile` | Perfil completo de un jugador |
| `recent-results` | Resumen de resultados recientes |
| `season-overview` | Resumen de una temporada completa |
| `tournament-summary` | Resumen de un torneo con resultados |

## Más Allá de los Datos de Partidos

Padel Analyst te da acceso a datos de rendimiento: rankings, resultados y estadísticas. Si también necesitas **análisis de engagement de fans**, consulta [Padel Fan Index](/guides/padel-fan-index), que combina estos datos con decisiones reales de fans de Fantasy Padel Tour.
