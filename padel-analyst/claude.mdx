Connect Padel Analyst from the Claude connectors directory, sign in with your Padel API account, and start asking about professional padel in your own words. It takes a couple of minutes and works on Claude's free plan.

<Note>
  Prefer to set up the connector yourself? Follow [Install in Claude via MCP](/padel-analyst/claude-custom-connector).
</Note>

## Prerequisites

<CardGroup cols={2}>
  <Card title="Claude Account" icon="user">
    The free plan is enough, no paid subscription required. Create yours at [claude.ai](https://claude.ai/) and sign in before you connect Padel Analyst.
  </Card>
  <Card title="Padel API Account" icon="key">
    A [Plus Plan](https://padelapi.org/billing) subscription or higher. You'll sign in with it during the installation to connect both accounts.
  </Card>
</CardGroup>

## Installation Steps

<Steps>
  <Step title="Open Padel Analyst in the Claude directory">
    Go to [Padel Analyst in the Claude directory](https://claude.ai/directory/padel-analyst) and click **Connect**.

    <Frame>
      <img src="/images/claude-directory/padel-analyst-claude-directory-connect.webp" alt="Padel Analyst page in the Claude connectors directory with its description, tools and connector details" />
    </Frame>
  </Step>

  <Step title="Authorize with your Padel API account">
    You're redirected to Padel API to sign in. Review the permissions Claude is requesting and click **AUTHORIZE**.

    | Permission | What it allows |
    |------------|----------------|
    | Use MCP tools to query padel data | Run queries about players, tournaments, matches and statistics |
    | Access MCP resources | Read reference data exposed by the server |
    | Use MCP prompts | Use the pre-configured analysis prompts |

    Once authorized, you're sent back to Claude.

    <Frame>
      <img src="/images/claude-directory/padel-analyst-claude-authorize-padel-api.webp" alt="Padel API authorization request screen granting Claude access to MCP tools, resources and prompts" />
    </Frame>
  </Step>

  <Step title="Start using Padel Analyst">
    Padel Analyst now appears in your connectors. Open a new chat and ask your first question.

    From then on you can use it in any chat, as described in [Using Padel Analyst in a chat](#using-padel-analyst-in-a-chat).

    <Frame>
      <img src="/images/claude-directory/padel-analyst-claude-ask-in-chat.gif" alt="Asking Claude who won the last Premier Padel tournament and getting the answer from Padel Analyst" />
    </Frame>
  </Step>
</Steps>

## Using Padel Analyst in a chat

The connector is available across your whole Claude account: claude.ai, the desktop app and the mobile apps. You only connect it once.

Click the **+** button next to the message box, open **Connectors** and make sure the **Padel Analyst** toggle is on:

<Frame>
  <img src="/images/claude-directory/padel-analyst-claude-plus-menu-enable-connector.webp" alt="Enabling the Padel Analyst connector from the Connectors submenu of the plus menu in a Claude chat" />
</Frame>

When Claude needs padel data, it asks for permission before calling a Padel Analyst tool. Click **Allow once** or **Always allow**.

## What you can ask

Ask in your own words, there's nothing to memorize. Anything about professional padel is fair game: players, pairs, tournaments, results, rankings, match statistics and predictions.

Some questions to get you started:

- "Who won the last Premier Padel Major?"
- "Show me the head-to-head between Lebron/Galan and Coello/Tapia"
- "What are Arturo Coello's statistics this season?"
- "List all P1 tournaments in 2025"
- "Simulate a match between the top two ranked pairs"

## Troubleshooting

<AccordionGroup>
  <Accordion title="Claude doesn't use Padel Analyst">
    Check that the **Padel Analyst** toggle is on in the **+** → **Connectors** menu of your chat. You can also mention it in your question, for example "Using Padel Analyst, who won the last Major?".
  </Accordion>
  <Accordion title="Padel Analyst doesn't answer with data">
    Check that your Padel API subscription is active on the [billing page](https://padelapi.org/billing). If it is, disconnect Padel Analyst and connect it again to sign in once more.
  </Accordion>
  <Accordion title="Something else isn't working">
    Write to [ferran@padelapi.org](mailto:ferran@padelapi.org) with a description of what you were doing and we'll take a look.
  </Accordion>
</AccordionGroup>

## Manage or remove the connector

Open **Settings → Connectors** in Claude and select **Padel Analyst**. From there you can review every tool the connector can use and choose, tool by tool, whether Claude should ask for permission or always allow it.

To remove it, click **Disconnect**. You can connect it again at any time from the [Claude directory](https://claude.ai/directory/padel-analyst).
