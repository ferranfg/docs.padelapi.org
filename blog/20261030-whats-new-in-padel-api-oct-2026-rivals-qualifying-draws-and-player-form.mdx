**Hello developers,**

The season is almost over, but we still have a few more things for you before the year ends. Here's what's new:

## 1. Rivals: who they always meet

Every player and every pair now has a list of **rivals**: the ones they have faced most, with the record, finals and titles against each of them.

It covers the whole history, so the long rivalries show up too, not only this season's. It takes the same filters as the stats endpoints, so you can narrow any rivalry down by dates, tournament level or round.

![Padel API Rivals](https://ik.imagekit.io/ferranfigueredo/padelapi/padelapi-rivals_Gl4Ucq-le.png)

Use it to add a "main rivals" section to a player profile, or to show in a match preview how many times both pairs have met and who usually wins.

[Player rivals](https://padelapi.org/docs/api-reference/player/show-player-rivals) · [Pair rivals](https://padelapi.org/docs/api-reference/pair/show-pair-rivals)

## 2. Qualifying draws

**Qualifying matches** are now in the API for Premier Padel and FIP Platinum, so tournaments start where they really start: qualifiers who reach the main draw come with the full path that took them there.

Listings still return the main draw by default, so nothing changes until you ask. Set `draw=qualy` for the qualifying matches only, or `draw=all` for the whole tournament in one request.

[List tournament matches](https://padelapi.org/docs/api-reference/tournament/list-tournament-matches)

## 3. Player form and pair synergy

Two new endpoints compare what players actually win against what was expected of them: **player form** tells you who is playing above their level, and **pair synergy** whether two players win more together than apart. Both return the gap and its trend.

![Padel API Form](https://ik.imagekit.io/ferranfigueredo/padelapi/padelapi-form_Teo-hE85K.png)

Why it matters: winning 70% of your matches is a poor run for the world number one and an outstanding one for a pair ranked 40th. Win rate alone does not tell them apart.

Use it to highlight the players in form ahead of a tournament, add a form badge to player cards, or spot the partnerships that work better than they should. Available on Business.

[Read the Player Form and Pair Synergy guide](https://padelapi.org/docs/guides/padel-form-and-synergy)
